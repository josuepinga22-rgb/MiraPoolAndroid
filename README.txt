MIRA POOL — projeto inicial para Android

O que esta versão faz:
- Abre uma mesa de sinuca de demonstração com tema preto.
- Primeiro toque posiciona a bola branca.
- Segundo toque posiciona a bola-alvo e desenha uma linha de direção simples.
- Botão RECOMEÇAR limpa a mesa.

Limitações importantes:
- Este é um protótipo manual; não captura a tela do 8 Ball Pool.
- Não injeta código, não altera o jogo e não oferece mira automática dentro dele.
- A linha é geométrica e não calcula colisões reais, força, efeito ou tabelas.
- Nenhum método pode garantir que uma ferramenta externa evite banimento.

Como gerar o APK:
1. Instale Android Studio em um computador.
2. Abra a pasta MiraPoolAndroid como projeto.
3. Aguarde a sincronização do Gradle.
4. Selecione Build > Build Bundle(s) / APK(s) > Build APK(s).
5. O APK de teste aparecerá em app/build/outputs/apk/debug/.

Requer Android 6.0 ou superior; compatível com Android 12.
